🛒 E-commerce REST API

Katalog produktów z zamówieniami zbudowany w Python + FastAPI + Pydantic. Wdrożony w chmurze na Railway.

🐍 Python ⚡ FastAPI ✅ Pydantic 🔐 JWT ☁️ Railway 🪣 AWS S3
📄 Swagger UI 🚀 Live API 📦 GitHub

Funkcje projektu

🔐

Autoryzacja JWT

Rejestracja i logowanie użytkowników. Chronione endpointy wymagają tokenu Bearer.

✅

Walidacja Pydantic

Wszystkie dane wejściowe są walidowane przez modele Pydantic z czytelnymi komunikatami błędów.

📦

Katalog produktów

Pełne operacje CRUD. Odczyt publiczny, modyfikacja wymaga autoryzacji JWT.

🧾

Zamówienia

Tworzenie zamówień z wielu produktów z automatycznym obliczaniem ceny.

📄

Swagger UI

Automatyczna interaktywna dokumentacja API dostępna pod adresem /docs.

☁️

Cloud Ready

Wdrożony na Railway z autodeploy z GitHub. Dokumentacja na AWS S3.

Endpointy API

Metoda Endpoint Opis Dostęp
POST /auth/register Rejestracja nowego użytkownika Publiczny
POST /auth/login Logowanie — zwraca token JWT Publiczny
GET /products Lista wszystkich produktów Publiczny
GET /products/{id} Jeden produkt po ID Publiczny
POST /products Dodaj nowy produkt 🔒 JWT
PUT /products/{id} Zaktualizuj produkt 🔒 JWT
DELETE /products/{id} Usuń produkt 🔒 JWT
POST /orders Utwórz zamówienie 🔒 JWT
GET /orders Moje zamówienia 🔒 JWT

Jak używać API

1

Zarejestruj się

POST /auth/register — wyślij {"email": "...", "password": "..."}

2

Zaloguj się i pobierz token

POST /auth/login — otrzymasz {"token": "eyJ..."}

3

Używaj tokenu w nagłówku

Dodaj do każdego chronionego żądania: Authorization: Bearer eyJ...

4

Lub użyj Swagger UI

Przejdź na /docs, kliknij Authorize i testuj endpointy bezpośrednio w przeglądarce.
