🛒 E-commerce REST API

Prosty katalog produktów z zamówieniami. Zbudowany w Node.js + Express, wdrożony na Railway.

🚀 Live API 📦 GitHub

O projekcie

🔐 Autoryzacja JWT

Rejestracja i logowanie użytkowników. Chronione endpointy wymagają tokenu Bearer w nagłówku Authorization.

📦 Katalog produktów

Pełne operacje CRUD na produktach. Publiczne odczytywanie, modyfikacja wymaga autoryzacji.

🧾 Zamówienia

Tworzenie zamówień z wielu produktów. Automatyczne obliczanie ceny całkowitej. Każdy użytkownik widzi tylko swoje zamówienia.

✅ Walidacja i błędy

Walidacja danych wejściowych, poprawne kody HTTP (400, 401, 403, 404, 409, 500), logika biznesowa oddzielona od kontrolerów.

Base URL

Produkcja: https://ecommerce-api-production-54f3.up.railway.app

Endpointy API

Metoda Endpoint Opis Dostęp
POST /auth/register Rejestracja nowego użytkownika Publiczny
POST /auth/login Logowanie — zwraca token JWT Publiczny
GET /products Lista wszystkich produktów Publiczny
GET /products/:id Jeden produkt po ID Publiczny
POST /products Dodaj nowy produkt 🔒 JWT
PUT /products/:id Zaktualizuj produkt 🔒 JWT
DELETE /products/:id Usuń produkt 🔒 JWT
POST /orders Utwórz zamówienie 🔒 JWT
GET /orders Moje zamówienia 🔒 JWT

Przykład użycia

1. Zarejestruj się

POST /auth/register → { "email": "...", "password": "..." }

2. Zaloguj się i pobierz token

POST /auth/login → { "token": "eyJ..." }

3. Używaj tokenu w nagłówku

Authorization: Bearer eyJ...
